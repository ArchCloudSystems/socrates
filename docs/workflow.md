# Workflow

## Observe
Read project state, git status, scripts, package manager, policy, and prior receipts.

## Plan
Produce a bounded plan with target files, commands, risks, verification steps, and rollback notes.

## Act
Early alpha does not perform broad file mutation. Future safe-write mode will require policy checks and receipts.

## Test
Run allowed checks and record results.

## Reflect
Summarize what happened and what should be learned.

## Receipt
Save evidence as markdown and JSON.

## Skillize
Convert repeated verified patterns into reusable skills.
