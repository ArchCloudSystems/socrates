# Product Design

Socrates is a terminal-first workbench for governed, receipt-driven software work.

It exists for builders who want AI agents to help with real software work without losing truth, safety, memory, or control.

## Core loop

```text
Observe → Plan → Act → Test → Reflect → Receipt → Skillize
```

## Roles

- Human: vision, correction, judgment, final authority.
- Socrates: governance, workflow, receipts, verification, skill import.
- Hermes: review, memory, repeated lesson discovery, skill proposals.
- Fable/GLM: high-reasoning planning and creative build lanes.
- AethosCore: visual J-space for declared operational state.

## Product law

Socrates does not visualize or expose hidden model thoughts. It records declared operational state: what was requested, observed, inferred, planned, changed, tested, reviewed, and learned.
